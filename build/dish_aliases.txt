# Names people search for dishes by, for extended-list foods whose source
# calls them something else: CoFID's "Curry, chick pea, whole and tomato"
# is what most people call chana masala.
#
# pattern | other names
#
# The pattern is a regular expression on the food's name (lower case, commas
# and brackets read as spaces); it may itself use |, so the LAST | on the line
# separates it from the names, which are separated by ;.
# Only names for the same dish -- not "close enough" ones -- and patterns
# specific enough not to catch an unrelated food.
